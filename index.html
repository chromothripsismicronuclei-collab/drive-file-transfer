Drive File Transfer Tool

本アプリケーションは、個人の業務効率化を目的として開発された、Google ドライブとローカル環境との間でファイルを転送するための非商用ツールです。一般公開・配布は行っておらず、開発者本人のみが利用します。

概要

  • Google ドライブ上の特定の1フォルダに限定して、ファイルの一覧取得・ダウンロード・アップロードを行います。
  • ローカル環境（開発者のPC）で動作するコマンドラインツールであり、サーバーや外部サービスは介在しません。
  • 広告配信・アクセス解析・トラッキングは一切行いません。

プライバシーポリシー

1. 取得する情報

本アプリケーションは、Google アカウントの認可（OAuth 2.0）により、以下へのアクセス権限を取得します。

  • Google ドライブ上のファイルおよびフォルダのメタデータ（ファイル名・ID・更新日時等）
  • Google ドライブ上のファイルの内容（ダウンロード・アップロードの対象となるもの）

氏名・住所・電話番号その他の個人を識別する情報を、利用者から別途収集することはありません。

2. 情報の利用目的

取得した情報は、利用者自身が明示的に指示したファイルの転送処理を実行する目的のみに使用します。それ以外の目的には使用しません。

3. 情報の保存

  • 認証情報（アクセストークン・リフレッシュトークン）は、利用者のローカル環境にのみ保存されます。
  • ダウンロードしたファイルは、利用者のローカル環境にのみ保存されます。
  • 開発者が運用するサーバーは存在せず、いかなるデータも外部に蓄積されません。

4. 第三者提供・外部送信

本アプリケーションが取り扱うデータを、第三者に提供・販売・貸与することはありません。また、Google API との通信を除き、データを外部のネットワークへ送信することはありません。

5. Google API Services ユーザーデータポリシーの遵守

本アプリケーションによる Google API から取得した情報の利用および他アプリへの提供は、 Google API Services User Data Policy （Limited Use の要件を含む）に準拠します。取得した情報を、機械学習モデルの学習、広告目的、または人間による閲覧のために使用することはありません。

6. アクセス権限の取り消し

利用者は、 Google アカウントの「サードパーティ アプリとサービス」 から、本アプリケーションへのアクセス権限をいつでも取り消すことができます。権限を取り消した時点で、本アプリケーションは一切のデータにアクセスできなくなります。
